# ⛽ Fuel Bot UA — Сервіс продажу талонів на пальне для мереж АЗС

Telegram-бот для автоматизації продажу та обліку електронних паливних талонів провідних українських мереж АЗС (**WOG, OKKO, Ukrnafta**).

Розроблено відповідно до вимог корпоративного ТЗ: трирівнева система цін, облік талонів з атомарним блокуванням, сценарії видачі QR-кодів та ручна валідація оплат.

---

## 🚀 Основний функціонал

* **Каталог мереж та пального:**
  * Мережі: **WOG, OKKO, Ukrnafta**.
  * Види пального: Бензин А-95, Дизель (ДП), Газ (LPG).
  * Номінали: 10 л, 20 л, 30 л, 50 л.
* **3 рівні цін (Multi-tier Pricing):**
  1. *Юридичні особи (ТОВ)* — розрахунковий рахунок з ПДВ.
  2. *ФОП* — прямий підприємницький рахунок (базовий тариф).
  3. *Криптовалюта (USDT TRC20)* — найнижча ціна з урахуванням курсу.
* **Сценарії заправки на АЗС:**
  * **WOG / Ukrnafta:** клієнт створює запит безпосередньо перед касою -> адміністратор надсилає індивідуальний QR-код -> списання після заправки.
  * **OKKO:** клієнт фотографує динамічний QR-код з екрана колонки -> надсилає в бот -> оператор підтверджує заправку.
* **Особистий кабінет клієнта:**
  * Баланс активних, зарезервованих та використаних талонів.
  * Історія замовлень та статусів.
* **Надійність та безпека:**
  * Асинхронний стек на базі **aiogram 3.x** та **aiosqlite / PostgreSQL**.
  * Захист від подвійного списання (атомарні статуси талонів).

---

## 🛠 Технологічний стек

* **Мова:** Python 3.11+ / 3.14
* **Фреймворк бота:** `aiogram 3.31.0` (сучасний асинхронний стандарт)
* **База даних:** `SQLite` (з підтримкою легкого переходу на `PostgreSQL` via `SQLAlchemy / asyncpg`)
* **Конфігурація:** `python-dotenv`

## 📦 Встановлення та запуск

1. **Клонуйте репозиторій або перейдіть у папку:**
   ```bash
   cd FuelBot_UA
   ```

2. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Налаштуйте змінні середовища:**
   Скопіюйте `.env.example` у `.env`:
   ```bash
   cp .env.example .env
   ```
   Вкажіть ваш `BOT_TOKEN`, отриманий від [@BotFather](https://t.me/BotFather).

4. **Запустіть бота:**
   ```bash
   python main.py
   ```
